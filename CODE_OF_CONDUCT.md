# Emberglass Community Conduct

We want a technical community where careful disagreement improves the software.

## Expected
- Be respectful and precise; critique arguments and code, not people.
- Explain assumptions when making a safety, performance or verification claim.
- Welcome contributors with different levels of systems-programming experience.
- Give credit for research, code and useful counterexamples.
- Respect maintainers' and contributors' time.

## Not acceptable
- Harassment, intimidation, hate speech, or personal attacks.
- Publishing someone else's private information.
- Abusive or discriminatory comments, repeated unwelcome contact, or deliberate disruption.
- Security-vulnerability disclosure that exposes users unnecessarily.

## Handling concerns
Maintainers at Bit Foundry Labs may moderate threads, remove abusive content, request a pause, or block repeat violators. If there is a safety or security issue, avoid sharing sensitive details in a public issue. Use GitHub's private vulnerability-reporting option if available; otherwise open a non-sensitive request for a private contact method without disclosing the details.

No one is required to tolerate harassment in order to contribute.
